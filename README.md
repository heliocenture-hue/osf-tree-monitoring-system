# OSF Tree Monitoring System

Plantation inventory and monitoring system for **Our Shoulders Foundation**.

## Overview
A lightweight web-based tree monitoring and inventory dashboard designed for tracking tree survival, growth parameters, GPS locations, maintenance logs, and QR code integration.

## Features
- **Key Metrics Dashboard**: Real-time summary of total trees, surviving count, casualty count, replacements, and survival rate.
- **Tree Inventory & Records**: Detailed tracking of common name, botanical name, plantation date, GPS coordinates, height, girth, and health condition.
- **Photo & Verification Support**: Local preview and image tracking for plantation verification.
- **Data Export & Local Persistence**: Export records as CSV and persist data locally in the browser.

## Files
- `index.html`: Main application entry point for web deployment (Vercel, GitHub Pages, etc.).
- `OSF_Tree_Monitoring_Editable.html`: Editable tree monitoring dashboard template.
